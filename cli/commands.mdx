---
title: CLI Commands
description: AgentOS command reference
---

| Command | Purpose |
| --- | --- |
| `health` | Check control-plane health |
| `providers` | Show configured authentication providers |
| `login google` | Print Google OAuth entry URL |
| `login github` | Print GitHub OAuth entry URL |
| `version` | Print CLI version |
| `help` | Print command help |

Example:

```bash
npx pravidhi-agentos@latest providers
```
