# Production Deployment

Pravidhi OS has two runtime layers:

1. Agent Control API — authenticated control plane on `/pravidhi/v3/`.
2. Python Runtime API — repository runtime on private `127.0.0.1:8765`.

Do not replace the control-plane service when deploying the Python runtime. Deploy it as the separate `pravidhi-runtime.service`.

## Install

```bash
git clone https://github.com/yashas-13/Pravidhi-OS.git /opt/pravidhi-os
cd /opt/pravidhi-os
python3 -m venv .venv
. .venv/bin/activate
pip install -e .
```

Create a dedicated `pravidhi` service account and install `deployment/pravidhi-runtime.service` as `/etc/systemd/system/pravidhi-runtime.service`.

The service listens only on localhost. Expose it through the existing Nginx TLS virtual host using `deployment/nginx-runtime.conf`.

## Validation

```bash
systemctl enable --now pravidhi-runtime
curl -fsS http://127.0.0.1:8765/health
curl -fsS https://pravidhisolutions.in/pravidhi/runtime/health
```

Provider API keys belong in `/etc/pravidhi-os.env`; never commit them to Git.
